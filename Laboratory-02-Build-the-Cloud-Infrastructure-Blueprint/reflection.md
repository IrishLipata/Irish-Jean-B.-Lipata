# Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think compute resources are one of the most important cloud infrastructure components because applications need processing power to perform tasks. Without CPU and memory, applications and services would not be able to run. However, compute also depends on storage, networking, and the operating system, so all of the components must work together.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing an operating system that can manage hardware and software resources on servers and virtual machines. Through the command line, cloud engineers can inspect system information, manage files, configure networking, and monitor resources. The KillerCoda activity helped me see how Linux commands can be used to examine a cloud server environment.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the infrastructure requirements, configurations, resources, and relationships between components. Good documentation can help reduce errors and make it easier for other team members to understand and manage the environment. It also provides a reference that can be used when troubleshooting or modifying infrastructure.

## 4. What new skills did you learn during this laboratory activity?

I learned how to use Linux commands to inspect a virtual machine's operating system, kernel, CPU, memory, storage, mounted filesystems, hostname, and IP address. I also practiced organizing technical information using Markdown and storing laboratory files in GitHub. In addition, I learned more about the infrastructure services provided by AWS, Microsoft Azure, and Google Cloud.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio has become more organized and useful because it now contains documentation about cloud infrastructure and Linux server information. Instead of only storing files, the repository shows evidence of my practical work and the skills I developed during the laboratory. This makes the repository a useful record of my progress in learning cloud computing.
