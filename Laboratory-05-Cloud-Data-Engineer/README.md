# Laboratory 05 - Cloud Data Engineer

## Mission Overview

In this laboratory activity, I deployed a live S3-compatible object storage server using MinIO and Docker. The activity focused on using object storage to store unstructured data such as images and demonstrating how a cloud storage service can be accessed through a web interface.

I deployed MinIO in a KillerCoda Ubuntu Playground, accessed the MinIO Web Console, created a secure `client-photos` bucket, and uploaded a test file to verify that the object storage system was working.

## Objectives

- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server using MinIO and Docker.
- Access a cloud service through a web interface using port forwarding.
- Create a storage bucket and upload an object.
- Document cloud storage operations using Markdown.
- Continue developing a professional Cloud Computing portfolio.

## Skills Learned

- Deploying containerized cloud services using Docker.
- Using Docker port mappings to access services through a web browser.
- Configuring applications using Docker environment variables.
- Working with S3-compatible object storage.
- Creating buckets and uploading objects using the MinIO Web Console.
- Verifying running Docker containers using the Linux command line.
- Documenting cloud infrastructure and technical procedures using Markdown.
