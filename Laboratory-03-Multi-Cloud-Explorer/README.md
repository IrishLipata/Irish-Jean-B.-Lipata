# Laboratory 03 – Multi-Cloud Explorer

## Mission Overview

In this laboratory activity, I explored and compared three major cloud computing platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). I researched their services, infrastructure, advantages, and common enterprise use cases. I also analyzed different business scenarios and recommended the cloud platform that I think best fits each client's needs.

## Cloud Platforms Explored

### Amazon Web Services (AWS)

I researched AWS and its major services, including Amazon EC2, Amazon S3, Amazon RDS, and Amazon VPC. I learned that AWS provides a wide range of cloud services and has a large global infrastructure.

### Microsoft Azure

I explored Microsoft Azure and learned about services such as Azure Virtual Machines, Azure Blob Storage, Azure SQL Database, and Azure Virtual Network. I also learned that Azure is a good option for organizations that already use Microsoft technologies.

### Google Cloud Platform (GCP)

I researched Google Cloud and its services, including Compute Engine, Cloud Storage, Cloud SQL, and Google Cloud VPC. I found that GCP is especially useful for Artificial Intelligence, Machine Learning, data analytics, and Kubernetes workloads.

## Cloud Platform Comparison

I compared AWS, Azure, and GCP based on their compute, storage, networking, identity, and other services. I also matched equivalent services between the three providers.

## Client Recommendations

I analyzed four different business scenarios and selected cloud platforms based on their requirements.

- **Startup Company:** AWS
- **University:** Microsoft Azure
- **AI Research Company:** Google Cloud Platform
- **Global E-Commerce Company:** AWS

I learned that choosing a cloud provider depends on the specific needs and goals of an organization.

## Linux Server Investigation

For the Linux investigation, I used the KillerCoda Playground to examine a Linux server using Linux commands. I checked the operating system, CPU information, memory, and disk space.

### Cloud Services That Could Host the Linux Server

If the Linux server were migrated to the cloud, it could be hosted using virtual machine services from each provider:

| Cloud Provider | Virtual Machine Service |
|---|---|
| AWS | Amazon EC2 |
| Microsoft Azure | Azure Virtual Machines |
| GCP | Compute Engine |

These services can provide virtual computing resources for running Linux-based applications and workloads.
